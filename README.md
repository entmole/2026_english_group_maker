# 함께 배우는 모둠 만들기

버디의 도움 서약만 보고 학생이 모둠을 고르는 **블라인드 모둠 편성** 도구입니다. 단일 `index.html` 파일로 동작합니다.

- 배포 주소: https://entmole.github.io/2026_english_group_maker/

## 진행 순서

| 단계 | 내용 |
| --- | --- |
| 1. 버디 등록 · 도움 서약 | 버디 6명의 이름과 한 문장 서약 입력 (모둠 번호 무작위 배정 가능) |
| 2. 블라인드 가치 선택 | **학생 태블릿(QR) 모드** 또는 **교사 입력 모드**로 학생 배치 |
| 3. 모둠 공개 · 이름표 | 버디 공개 → **모둠 이름표**(모둠별 A4) 인쇄, 필요 시 협동 서약서 인쇄 |

## 2단계 모드

| 모드 | 방식 |
| --- | --- |
| 📱 학생 태블릿(QR) | 교사 화면의 QR(또는 8자리 방 코드)로 접속 → 학년·반·번호·이름 입력 → 약속 카드 선택 → 제출. 버디 이름은 태블릿에 전송되지 않습니다. |
| ⌨️ 교사 입력 | 교사가 학생 이름을 입력(또는 명단 적용)하고 카드를 눌러 배치합니다. 이 모드에서는 태블릿 접수가 멈춥니다. |

- 학생은 학년·반·번호·이름과 함께 **성별(남학생/여학생)** 을 선택해야 제출할 수 있습니다.
- **성별 상한**(기본 모둠별 남 2명·여 2명)을 켜면, 자기 성별 자리가 찬 약속 카드는 그 학생에게 "마감"으로 보입니다. 설정은 2단계 왼쪽 **설정** 패널에서 바꾸거나 끌 수 있습니다.
- 성별 상한에는 **버디도 포함**됩니다(1단계에서 버디 성별 입력). 예: 남 2명 상한 + 남자 버디 → 남학생 1명만 더 받습니다.
- 교사 화면의 성별별 인원은 버디 성별이 드러나지 않도록 **배치 현황 보기**에서만 표시됩니다. 단, 태블릿의 "남은 자리" 표시로 버디 성별을 짐작할 수는 있습니다.
- 같은 학년·반·번호의 중복 제출, 마감된 약속·성별 자리 선택, 버디 본인의 지원은 교사 PC에서 다시 확인해 거부합니다.
- 교사 입력 모드에서는 학생마다 남/여를 고릅니다. 명단에 `김하늘 여`, `이도윤/남`, `박서연(여)`처럼 적으면 성별이 자동으로 지정됩니다.
- 공용 태블릿은 제출 후 “다음 친구 입력하기”로 이어서 사용합니다(학년·반은 유지).

## 3단계 모둠 이름표

- A4 세로 접이식 양식입니다. 위쪽 칸(**Buddy · Representer · Recorder · Team manager**)은 접었을 때 반대편에서 읽히도록 거꾸로 인쇄되고, 아래 칸은 **Team name**을 손으로 쓰는 칸입니다.
- Buddy는 버디 이름으로 자동 입력됩니다. 나머지 역할은 모둠원 중에서 고르거나, **역할 무작위 배정**을 쓰거나, 비워 두고 학생이 직접 씁니다.
- **인쇄: 모둠별 A4 이름표**를 누르면 모둠마다 1장씩(총 6장) 여백 없이 인쇄됩니다.

## 엑셀 내보내기

3단계에서 버디를 공개한 뒤 **📥 엑셀로 내려받기**를 누르면 `groups_날짜.xlsx` 파일이 저장됩니다.

| 시트 | 내용 |
| --- | --- |
| 모둠 편성 | 한 줄에 한 명: 모둠, 구분(버디/모둠원), 이름, 성별, 학년, 반, 번호, 역할, 버디 도움 서약 |
| 모둠별 요약 | 한 줄에 한 모둠: 버디, 도움 서약, 모둠원 이름, 남·여 인원, 총 인원 |

## 엑셀 불러오기 · 학생 이동

- 화면 오른쪽 위 **📤 엑셀 불러오기**로 이 앱에서 내려받은 엑셀을 고르면, 버디·모둠원·성별·학년반번호·역할을 복원하고 3단계 **👥 모둠 구성** 탭으로 이동합니다.
- 엑셀에서 **모둠** 번호를 직접 고친 뒤 불러와도 그대로 반영됩니다. 모둠 번호·이름이 비어 있는 줄은 건너뛰고 몇 줄을 건너뛰었는지 알려 줍니다.
- **👥 모둠 구성** 탭에서 학생을 다른 모둠으로 **끌어다 놓거나**, 이름 옆 **[이동…]** 에서 모둠을 고르면 옮겨집니다(태블릿·터치 화면은 [이동…] 사용).
- 인원·성별 상한을 넘어도 교사 판단으로 옮길 수 있으며, 넘은 항목은 빨간색으로 표시됩니다. 옮긴 학생의 역할(Representer 등)은 비워집니다.
- 옮긴 결과는 이름표·서약서·엑셀 내보내기에 그대로 반영됩니다.

## 태블릿 연결 방식

- 교사 PC와 태블릿은 공개 중계 서버 **ntfy.sh**(HTTPS 443 포트)를 거쳐 메시지를 주고받습니다. 별도 가입·설정은 필요 없습니다.
- 메시지는 방 코드에서 만든 키로 **암호화(AES-GCM)** 되며, 중계 서버에는 방 코드와 학생 이름이 그대로 전달되지 않습니다.
- **교사 화면이 열려 있어야** 제출이 처리됩니다. 교사 화면을 잠시 닫았다 열면 그 사이의 제출도 이어서 처리합니다.

### 사용 한도 (ntfy.sh 공개 서버 기준)

| 항목 | 한도 | 이 앱의 사용량 |
| --- | --- | --- |
| 하루 메시지 | 접속 IP당 **250건** | 학생 1명 제출 ≈ 1~2건 → 30명 학급 1회 ≈ 40~60건 |
| 동시 연결 | 접속 IP당 **30개** | 태블릿은 제출을 마치면 연결을 닫음 |
| 요청 | IP당 60건 후 5초마다 1건 충전 | 상태 전송을 1.2초 단위로 묶어 절약 |

- 학교 전체가 하나의 공인 IP를 쓰는 경우가 많아, **하루 4~5개 학급** 정도가 무난한 사용량입니다.
- 한도를 넘으면 교사 화면에 안내가 뜨며, 이때는 **교사 입력 모드**를 사용하세요.
- 사용량이 더 필요하면 자체 ntfy 서버를 설치하고 `index.html`의 `RELAY` 주소만 바꾸면 됩니다.
