# 함께 배우는 모둠 만들기

버디의 도움 서약만 보고 학생이 모둠을 고르는 **블라인드 모둠 편성** 도구입니다. 단일 `index.html` 파일로 동작합니다.

## 진행 순서

| 단계 | 내용 |
| --- | --- |
| 1. 버디 등록 · 도움 서약 | 버디 6명의 이름과 한 문장 서약 입력 (모둠 번호 무작위 배정 가능) |
| 2. 블라인드 가치 선택 | **학생 태블릿(QR) 모드** 또는 **교사 입력 모드**로 학생 배치 |
| 3. 모둠 공개 · 협동 서약서 | 버디 공개, 서약서 인쇄(A4 한 장 / 모둠별 한 장), 텍스트 복사 |

## 2단계 모드

| 모드 | 방식 |
| --- | --- |
| 📱 학생 태블릿(QR) | 교사 화면의 QR(또는 6자리 방 코드)로 접속 → 학년·반·번호·이름 입력 → 약속 카드 선택 → 제출. 버디 이름은 태블릿에 전송되지 않습니다. |
| ⌨️ 교사 입력 | 교사가 학생 이름을 입력(또는 명단 적용)하고 카드를 눌러 배치합니다. 이 모드에서는 태블릿 접수가 멈춥니다. |

- 같은 학년·반·번호의 중복 제출, 마감된 약속 선택, 버디 본인의 지원은 교사 PC에서 거부합니다.
- 접수 마감/재개, 방 코드 재발급, 마지막 선택 되돌리기, 개별 학생 빼기를 지원합니다.
- 공용 태블릿은 제출 후 “다음 친구 입력하기”로 이어서 사용합니다(학년·반은 유지).

## QR 모드 사용 준비

학생 태블릿이 접속하려면 `index.html`이 **인터넷 주소(HTTPS)** 로 열려 있어야 합니다. GitHub Pages가 가장 간단합니다.

1. 저장소 **Settings → Pages** 이동
2. **Source: Deploy from a branch**, 브랜치와 `/ (root)` 선택 후 저장
3. `https://<아이디>.github.io/<저장소>/` 주소로 교사 PC에서 접속

파일을 PC에서 직접 연 경우(`file://`)에는 2단계 QR 패널의 **학생용 공개 주소** 칸에 위 주소를 입력하면 QR이 생성됩니다.

## 연결 방식과 주의 사항

- 교사 PC와 태블릿은 **PeerJS(WebRTC P2P)** 로 직접 연결됩니다. 별도 서버·계정 설정이 필요 없으며, 연결 중계에 PeerJS 공개 서버(`0.peerjs.com`)를 사용합니다.
- **교사 화면이 열려 있어야** 제출을 받습니다. 배치 데이터는 교사 PC 브라우저(localStorage)에만 저장됩니다.
- 학교 Wi-Fi에서 기기 간 통신(AP 격리)이나 WebRTC가 차단되면 연결되지 않을 수 있습니다. 이 경우 교사 입력 모드를 사용하거나 네트워크 담당자에게 문의하세요.
- 자체 PeerJS 서버를 쓰려면 `index.html`의 `PEER_OPTS`에 `host`, `port`, `path`를 지정합니다.
